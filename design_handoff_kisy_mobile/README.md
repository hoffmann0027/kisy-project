# Handoff: KISY — редизайн мобильного мессенджера

## Overview

Редизайн мобильной части KISY: навигация переведена с бокового drawer'а на нижний таб-бар с центральным «орбом», второстепенные разделы собраны в новый экран «Хаб». В пакете проработаны Сообщения (три состояния), Чат, Хаб, drawer и таб-бар. Сообщества, Рейтинг проектов и Профиль показаны как заглушки — их предметное наполнение во втором проходе.

Цель задачи: воспроизвести эти экраны в существующем фронтенде KISY (`hoffmann0027/kisy-project`, `frontend/`, React + TypeScript + Vite), используя уже имеющиеся компоненты и токены.

## About the Design Files

Файлы в этом пакете — **дизайн-референсы, сделанные в HTML**. Это прототипы, показывающие внешний вид и поведение, а не production-код для копирования. Разметка написана в собственном шаблонном формате (`<sc-if>`, `<sc-for>`, `{{ }}`, инлайновые стили) — он существует только в среде, где дизайн создавался, и переносить его в кодовую базу не нужно.

Задача — пересобрать эти экраны в среде целевого проекта: React-компоненты в `frontend/src`, стили через CSS-переменные из `shared/config/theme.css` и классы из `shared/ui/ui.css`, иконки из `shared/ui/icons.tsx`. Значения в этом README приведены в пикселях и хексах, чтобы можно было сверить результат; но там, где в коде уже есть токен или компонент, использовать нужно его, а не литерал.

## Fidelity

**High-fidelity.** Цвета, типографика, отступы и радиусы финальные, состояния проработаны. UI следует воспроизвести пиксельно точно — но через существующие компоненты (`Button`, `Input`, `Avatar`, `Badge`, `IconButton`) и токены, а не новыми литералами.

Два исключения, где дизайн отклоняется от кода осознанно (см. «Расхождения с кодом»): плавающий таб-бар вместо рейла 58px и бренд-градиент на ободе орба.

## Interactions & Behavior

Навигация:
- тап по строке чата → экран Чат с этим собеседником (имя и инициалы в шапке — из выбранной строки)
- «назад» в чате → Сообщения
- орб → Хаб, активный слот таб-бара переходит в состояние «хаб» (ни один из четырёх боковых табов не подсвечен)
- боковые табы → соответствующий экран; Сообщества / Рейтинг / Профиль ведут на заглушку
- аватар в шапке → drawer; закрытие по кнопке X или тапу по затемнению
- таб-бар скрыт только на экране Чат

Фильтры Сообщений — клиентская фильтрация загруженного списка, без запроса:
- «Все» — всё
- «Непрочитанные» — только с `unread > 0`
- «Упоминания» — только помеченные упоминанием

Композер:
- иконка кнопки отправки переключается Mic ↔ Send по `draft.trim().length > 0`
- отправка добавляет исходящее сообщение в конец ленты, очищает поле и закрывает панель форматирования; при пустом (только пробелы) поле — no-op
- «Aa» переключает панель форматирования и own активное состояние

Анимации (все три объявлены как `@keyframes`, длительности финальные):
- `kisy-shimmer` — 1.6s `ease-in-out` infinite, `opacity` .35 → .75 → .35 (скелетоны)
- `kisy-float` — 6s `ease-in-out` infinite, `translateY` 0 → −6px → 0 (иллюстрация пустого состояния)
- `kisy-rise` — .18–.2s `ease-out`, `opacity` 0→1 + `translateY` 10px→0 (панель форматирования, drawer)

Уважайте `prefers-reduced-motion`: `kisy-float` и `kisy-shimmer` — бесконечные, их нужно отключать.

Состояния наведения и нажатия: строка чата и строки списков подсвечиваются `rgba(255,255,255,0.04)` (в коде это токен `--hover`). Для кнопок используйте hover/active из `.ui-btn` без переопределений.

## State Management

Локальное состояние экрана мессенджера:

| Переменная | Тип | Назначение |
|---|---|---|
| `screen` | `'messages' \| 'chat' \| 'hub' \| 'stub'` | текущий экран |
| `tab` | `'messages' \| 'communities' \| 'rating' \| 'profile' \| 'hub'` | подсветка таб-бара |
| `drawer` | `boolean` | drawer открыт |
| `filter` | `'all' \| 'unread' \| 'mentions'` | активный фильтр списка |
| `activeChat` | id / индекс | выбранный диалог |
| `draft` | `string` | текст в композере |
| `fmt` | `boolean` | панель форматирования открыта |

В прототипе `screen` и `tab` — локальный стейт; в приложении это маршруты, а `tab` вычисляется из текущего пути. `drawer`, `filter`, `draft`, `fmt` остаются локальными.

Данные: список диалогов (инициалы или аватар, имя, превью последнего сообщения, время, счётчик непрочитанного, онлайн-статус, флаг упоминания) и сообщения выбранного диалога (текст, время, направление, признак прочтения). Загрузка списка показывает скелетоны; пустой ответ — пустое состояние. Отправка в прототипе оптимистичная, серверного подтверждения нет.

## Расхождения с кодом

Осознанные отклонения — их стоит принять или отклонить явно:

1. **Таб-бар.** В коде рейл `--rail-h: 58px`, прижат к низу. В дизайне — плавающая капсула 64px с отступом `calc(22px + env(safe-area-inset-bottom))`. Требует правки `--rail-h` / `--rail-total` и нижних отступов скроллящихся контейнеров (в дизайне 110–120px).
2. **`--brand-grad`.** Оранжевого градиента из логотипа в `theme.css` нет — нужен новый токен. Использован ровно в одном месте интерфейса (обод орба), чтобы не конкурировать с фиолетовым акцентом.
3. **Орб и чипы-фильтры.** Новые компоненты, в `ui.css` аналогов нет.
4. **`.ui-icon-btn`.** В коде 38px. В дизайне визуальный размер сохранён, но зона нажатия расширена до 44px — минимум для мобильных таргетов.
5. **Штрих иконок** — 1.5 вместо 2 (см. выше).
6. **`KISY_design_spec.md`** в репозитории описывает другую палитру (Apple Pro dark, `#2997ff`, SF Pro, Tabler Icons) для лендинга и экрана звонка. Мобильный редизайн сделан по текущему UI и брифу, а не по этой спеке. Расхождение спеки с кодом стоит решить отдельно — оно существовало до этой работы.
