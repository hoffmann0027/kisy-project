# Производительность холодного старта

## Почему это документ, а не задача в трекере

Бандл растёт незаметно: каждая новая страница добавляет пару десятков
килобайт, и однажды телефон начинает открывать приложение секунды. Здесь
зафиксированы цифры и правила, по которым их держат.

## Метод

```bash
cd frontend && npm run build        # размеры чанков печатает сам vite
```

Размеры ниже — вывод `vite build` (raw / gzip). Проверка того, что
попадает на критический путь, — `performance.getEntriesByType('resource')`
в открытом приложении: чанк, которого там нет до первого экрана, старт не
задерживает.

## Было (до правки, коммит f349729)

| Чанк | Размер | gzip |
| --- | --- | --- |
| `index-*.js` (**весь код приложения**) | 1 672,84 КБ | 514,20 КБ |

Один чанк на всё: страницы рейтинга и админки, девять модалок,
`libsodium-wrappers-sumo`, `ts-mls`, `recharts` — всё это телефон скачивал и
парсил до первой отрисовки списка чатов. `React.lazy` в `app/router.tsx` не
использовался ни разу, `manualChunks` в `vite.config.ts` не было.

## Стало

| Чанк | Размер | gzip | Когда грузится |
| --- | --- | --- | --- |
| `index-*.js` | 488,33 КБ | **151,38 КБ** | старт |
| `sodium-*.js` | 535,29 КБ | 187,04 КБ | при первом обращении к крипте |
| `RatingPage-*.js` (с `recharts`) | 436,61 КБ | 118,05 КБ | переход на `/rating` |
| `mls-*.js` | 123,05 КБ | 32,43 КБ | при первом обращении к крипте |
| `query-*.js` | 51,09 КБ | 15,67 КБ | старт |
| `AdminPage-*.js` | 7,30 КБ | 2,60 КБ | переход на `/admin` |
| `HubPage-*.js` | 2,76 КБ | 1,20 КБ | переход на `/hub` |
| модалки (`NotesModal`, `VotingModal`, …) | по 2–20 КБ | | при первом открытии |

**Входной чанк: 514,20 → 151,38 КБ gzip (−70%)**, цель «< 500 КБ gzip»
выполнена с запасом.

Проверено в браузере: `recharts` появляется в списке ресурсов только после
перехода на `/rating`; чанк модалки заметок — только после её открытия.

## Правила, которые нельзя нарушать

- **Экран — только через `React.lazy`.** Новый маршрут, добавленный обычным
  импортом в `app/router.tsx`, возвращает нас к одному чанку.
- **Модалка монтируется только открытой** (`{open && <Modal …/>}`), а не
  всегда с `open={false}`. `Modal` и так рисует `null` закрытым, но её код и
  запросы при этом уже в памяти.
- **Тяжёлая библиотека — в свой чанк** через `manualChunks`. Сейчас там
  `libsodium`, `ts-mls`, `@noble/*`, `react-query`.
- **Крипта не блокирует первый экран.** `initE2EE` вызывается из эффекта без
  `await` (`app/useRealtime.ts`), UI рисуется из кэша react-query, сообщения
  дорасшифровываются по готовности. Если когда-нибудь появится `await` перед
  первой отрисовкой — старт снова упрётся в 500+ КБ крипты.

## Что здесь не измерено

**TTI на реальном Android** — этих цифр в документе нет: снять их можно
только на устройстве через `chrome://inspect` → Performance, машина сборки
этого не заменяет. Целевое значение < 2,5 с при тёплом кэше; замеряется
вручную при подготовке релиза (см. `docs/mobile.md`).
