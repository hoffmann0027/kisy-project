# Логотип и производные иконки

`logo-source.png` — мастер-артворк (1254×1254, октябрь 2026): знак «K» в
пузыре внутри светящейся стеклянной плашки, в духе прозрачных иконок iOS 26.
Фон вокруг плашки и внутри неё прозрачный. Всё остальное генерируется из
него, вручную иконки не правим — иначе комплекты разъезжаются.

Иконка — **вся плашка целиком**, вместе с рамкой: это и есть стеклянный
стиль. Скрипт добавляет к ней одно: лёгкий матовый слой внутри рамки
(`FROST_TOP` → `FROST_BOTTOM`, сверху светлее). Без него на пёстрых обоях
плашка читается как пустой контур, с ним — как пластина стекла, сквозь
которую видно фон.

## Как перегенерировать

```bash
cd design && npm i sharp && node generate-icons.js
```

Скрипт кладёт файлы на их места и печатает список. После него:

- поднять `?v=` у `logo.png` в `frontend/src/shared/ui/Logo.tsx`, у иконок в
  `frontend/index.html`, `frontend/public/manifest.webmanifest` и
  `frontend/public/sw.js` (там же — `CACHE`): браузер и установленное PWA
  кешируют иконки намертво;
- пересобрать Android-сборку (иконки вшиты в APK).

## Что откуда берётся

| Файл | Что это |
| --- | --- |
| `public/logo.png` | знак внутри приложения — прозрачное стекло, сквозь него видна любая из семи тем |
| `public/favicon.png`, `icon-192`, `icon-512` | то же прозрачное стекло |
| `public/apple-touch-icon` | плашка на `#0B0C14`: iOS заливает прозрачную иконку «на экране Домой» чёрным |
| `public/icon-maskable-512` | плашка в 60% канвы на `#0B0C14` — Android режет по своей маске и ничего не подкладывает |
| `mipmap-*/ic_launcher`, `ic_launcher_round` | лаунчер до Android 8: прозрачное стекло, 92% и 82% |
| `mipmap-*/ic_launcher_foreground` | adaptive-иконка (Android 8+): 54% канвы — так плашка с рамкой целиком влезает даже в круглую маску; фон `values/ic_launcher_background.xml` прозрачный |
| `design/play-icon-512.png` | иконка для Google Play: 512×512 без прозрачности, плашка на `#0B0C14` — стор сам скругляет углы |
| `drawable-*/splash.png` | сплэш, плашка в 38% меньшей стороны на `#0B0C14` |

Где кончается «снаружи», скрипт находит заливкой от краёв картинки по
пикселям прозрачнее `FRAME_ALPHA`: рамка её останавливает. Если в новом
артворке рамка окажется с разрывом, скрипт остановится с ошибкой, а не
зальёт стеклом весь квадрат.
