# Логотип и производные иконки

`logo-source.png` — мастер-артворк (1254×1254): знак «K» в пузыре + подпись
KISY MESSENGER на чёрном. Всё остальное генерируется из него, вручную иконки
не правим — иначе комплекты разъезжаются.

## Как перегенерировать

```bash
cd design && npm i sharp && node generate-icons.js
```

Скрипт кладёт файлы на их места и печатает список. После него:

- поднять `?v=` у `logo.png` в `frontend/src/shared/ui/Logo.tsx` и у иконок в
  `frontend/index.html` и `frontend/public/manifest.webmanifest` — браузер и
  установленное PWA кешируют иконки намертво;
- пересобрать Android-сборку (иконки вшиты в APK).

## Что откуда берётся

| Файл | Что это |
| --- | --- |
| `public/logo.png` | знак внутри приложения — **прозрачный фон**, потому что лежит на любой из семи тем |
| `public/favicon.png`, `icon-192`, `icon-512`, `apple-touch-icon` | знак на тёмной плашке: они сидят на хромке ОС/браузера |
| `public/icon-maskable-512` | знак в 60% канвы — Android режет по своей маске |
| `mipmap-*/ic_launcher` | лаунчер, 86% канвы |
| `mipmap-*/ic_launcher_round` | круглая маска кусает углы, поэтому 72% |
| `mipmap-*/ic_launcher_foreground` | adaptive-иконка: прозрачный фон, 62% (safe zone), фон задаёт `values/ic_launcher_background.xml` |
| `drawable-*/splash.png` | сплэш, знак в 38% меньшей стороны на `#0B0C14` |

Прозрачность получается из яркости: артворк нарисован светом по чёрному,
поэтому `alpha = max(r,g,b)`. Порог `ALPHA_FLOOR` отсекает виньетку фона —
без него на светлых темах вокруг знака проявляется серый квадрат.
